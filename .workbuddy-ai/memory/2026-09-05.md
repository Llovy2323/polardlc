### Что за проект
SNILL / Polar DLC — Fabric мод-чит-клиент для Minecraft Java 1.21.4.
Стек: Fabric Loom 1.10, Gradle 9.3.0, Java 21, Yarn 1.21.4+build.8, loader 0.18.4, Fabric API 0.119.2.

Объём: 351 java-файл, ~51 800 строк, 56 миксинов, ~80 модулей, 12 команд.
Собранный jar лежит в build/libs/snill-1.0.0.jar (23 МБ) — проект компилировался.

Структура:
- api/ — event bus (EventInvoker/EventLink), storages (config, friend, macro, waypoint, alt, theme), utils (render, math, combat, rpc, script/LuaJ)
- client/modules/impl/ — combat, movement, player, render, misc
- client/ui/ — MenuPanel + clickgui, altmanager, space
- mixin/ — 56 миксинов
- mods/ — кастомные партиклы (maseffects, particular)

### Находки
- `ru.virtuoz.client.User` — native (JNI) методы авторизации. Вызовов в коде НЕТ — мёртвый код, выпиливается безболезненно.
- `ru.virtuoz.convert.Convert` — аннотации-маркеры обфускатора, на компиляцию не влияют.
- Baritone задействован слабо: только BaritoneAntiStuck + 2 миксина. Легко выкинуть или заменить.
- Discord RPC через JNA + resources/win32-x86-64/discord-rpc.dll.
- Snill.java использует `WorldRenderEvents.START` — это API Fabric, который убирали и возвращали с новым контрактом. Ломается при порте.

### Версии Minecraft (проверено)
- 1.21.11 — последняя обфусцированная версия. Fabric поддерживает, Yarn есть, Loom 1.14.
- Дальше Mojang сменил нумерацию: 26.1, 26.2 (релиз 16.06.2026). Версии "1.26.x" НЕ существует.
- 26.1+ — код без обфускации. Yarn и Intermediary больше не обновляются, обязателен переезд на Mojang Mappings (Loom migrateMappings или плагин Ravel).
- 26.2 требует Java 25, Loom 1.17, Gradle 9.5.1. Бинарной совместимости нет — всё перекомпилировать.
- Baritone: на 1.21.11 есть форки, на 26.x — под вопросом.

Порт сразу на 26.2: это не порт, а переезд + смена маппингов, в 2-3 раза дольше.
Предложил двухэтапный путь: сначала 1.21.11 с параллельным рефакторингом, потом 26.x.
